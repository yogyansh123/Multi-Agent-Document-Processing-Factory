# Demo Checklist & Walkthrough Guide

> **Platform**: Multi-Agent Document Processing Factory  
> **Duration**: 5–10 Minutes  
> **Audience**: Technical Leads, Architects, and Product Stakeholders  

---

## 1. Environment & Service URLs

Before starting the demonstration, verify the service endpoints:

| Interface | URL | Description |
|---|---|---|
| **Production Web UI** | [http://localhost:5173](http://localhost:5173) | Main React SPA Dashboard |
| **FastAPI Swagger Docs** | [http://localhost:8000/docs](http://localhost:8000/docs) | Interactive OpenAPI Reference |
| **System Readiness** | [http://localhost:8000/health/ready](http://localhost:8000/health/ready) | Dependency health diagnostics |
| **Temporal Web UI** | [http://localhost:8088](http://localhost:8088) | Workflow execution traces |

---

## 2. Step-by-Step Demonstration Script (5–10 Minutes)

### Step 1: Open the Operations Dashboard
- **URL**: `http://localhost:5173/`
- **What to show**:
  - Top KPI cards: Total Documents, Approved, Pending Review, Overall Confidence score.
  - Active Pipeline Stepper illustrating the 8-stage document lifecycle.
  - Live Infrastructure status indicator (PostgreSQL, Redis, Temporal health).

---

### Step 2: Upload a Business Document
- **URL**: `http://localhost:5173/upload` (or click "Upload Document" in navbar)
- **What to show**:
  - Drag-and-drop file upload zone.
  - Select a sample invoice PDF (e.g., `samples/invoice_001.pdf`).
  - Demonstrate instant client-side format and size validation.
  - Click **Upload Document** and observe the progress bar.
  - Notice the automatic transition to the **Document Cockpit** (`/documents/:id`) with status `UPLOADED`.

---

### Step 3: Trigger Distributed Workflow
- **URL**: `http://localhost:5173/documents/:id`
- **What to show**:
  - Click the **Start Processing** button (`POST /api/v1/documents/:id/process`).
  - Explain that Temporal orchestrates 5 sequential idempotent activities:
    1. `run_ocr`
    2. `classify_document`
    3. `extract_fields`
    4. `validate_document`
    5. `score_confidence`
  - Show the live visual stepper updating with smooth animated transitions.

---

### Step 4: Inspect OCR Results
- **URL**: `http://localhost:5173/documents/:id` (OCR Tab)
- **What to show**:
  - Raw extracted text preview with monospace font.
  - Page count indicator, execution latency (ms), and OCR engine attribution (Tesseract / Direct parser).

---

### Step 5: Inspect Document Classification
- **URL**: `http://localhost:5173/documents/:id` (Overview Tab)
- **What to show**:
  - Classified document type badge (e.g., `INVOICE`).
  - Classification confidence score (e.g., `96.5%`).
  - LangGraph classification signals (e.g., detected keywords: "Invoice Number", "Tax Due", "Net 30").
  - Decision reasoning generated by the classification agent.

---

### Step 6: Review Structured Information Extraction
- **URL**: `http://localhost:5173/documents/:id` (Extracted Data Tab)
- **What to show**:
  - Strongly typed Pydantic schema rendering:
    - **Header**: Invoice Number, Invoice Date, Due Date, Currency (`USD`).
    - **Entities**: Vendor name & address, Customer name & billing address.
    - **Line Items Table**: Description, Quantity, Unit Price, Line Total.
    - **Financials**: Subtotal, Tax, and Grand Total Amount.

---

### Step 7: Examine Validation Rules & Confidence Score
- **URL**: `http://localhost:5173/documents/:id` (Validation & Confidence Section)
- **What to show**:
  - **Deterministic Rules**: Line item arithmetic, subtotal sum check, date order consistency (`due_date >= invoice_date`).
  - **Confidence Factor Breakdown**:
    - Classification: 25% weight
    - Extraction completeness: 35% weight
    - Validation consistency: 40% weight
  - **Routing Decision**:
    - Score $\ge 0.85$ and no validation errors $\rightarrow$ **AUTO_APPROVE**
    - Score $< 0.85$ or validation errors $\rightarrow$ **REVIEW_REQUIRED**

---

### Step 8: Human-in-the-Loop Review (If Applicable)
- **URL**: `http://localhost:5173/reviews`
- **What to show**:
  - Filter review queue by status (`PENDING`, `IN_REVIEW`).
  - Click **Start Review** on an item to claim ownership.
  - Navigate to `/reviews/:id` showing side-by-side view:
    - Left: Raw OCR text and flagged validation issues.
    - Right: Editable structured fields with validation hints.
  - Edit a field (e.g., correct a mismatched subtotal).
  - Click **Submit Correction & Revalidate**.
  - Highlight that the system re-runs deterministic validation rules on corrected data and records audit logs.

---

### Step 9: Automatic RAG Indexing Verification
- **URL**: `http://localhost:5173/documents/:id`
- **What to show**:
  - Document status transitions to `APPROVED`.
  - The **RAG Indexed** green badge activates (`rag_indexed = true`).
  - Explain that approved documents are automatically chunked (800 chars, 120 overlap, page preservation) and indexed into PostgreSQL + pgvector.

---

### Step 10: Document Intelligence (RAG Query)
- **URL**: `http://localhost:5173/rag`
- **What to show**:
  - Enter natural language queries:
    - *"What is the total amount due on invoice INV-2026-999?"*
    - *"Who is the vendor and what are the payment terms?"*
  - **Grounded Answer**: Show generated response.
  - **Traceable Source Citations**: Click citation card showing document filename, page number, snippet excerpt, and vector similarity match percentage.
  - **Anti-Hallucination Behavior**: Ask an unanswerable question (*"What is the corporate jet model?"*) $\rightarrow$ show system returns:
    *"I could not find sufficient evidence in the indexed documents."*

---

### Step 11: Real-Time Operational Analytics
- **URL**: `http://localhost:5173/analytics`
- **What to show**:
  - Real-time KPI summary (Total Docs, Auto-Approval Rate, Average Review Time).
  - Interactive Date Range Presets: **7D**, **30D**, **90D**, **All**, **Custom**.
  - Pipeline Stage Latency chart showing millisecond durations for OCR, Classification, Extraction, Validation.
  - Review Queue Workload & Decision Breakdown (Approved vs. Corrected vs. Rejected).
  - Interactive SVG Throughput bar chart with daily/weekly buckets.
  - Live 60-second background polling with manual **Refresh** button.

---

### Step 12: System Health & Infrastructure Monitoring
- **URL**: `http://localhost:5173/health`
- **What to show**:
  - Real-time dependency health cards:
    - **FastAPI Backend**: Healthy / Uptime.
    - **PostgreSQL + pgvector**: Connected, vector extension active.
    - **Redis**: Status cache active, sub-millisecond response.
    - **Temporal Orchestrator**: Cluster healthy, task queue active.

---

### Step 13: Temporal Workflow Traces (When Docker Stack is Running)
- **URL**: `http://localhost:8088/namespaces/document-processing/workflows`
- **What to show**:
  - Workflow ID: `document-processing-{document_id}`
  - Execution history graph showing sequential activity progression:
    `run_ocr` $\rightarrow$ `classify_document` $\rightarrow$ `extract_fields` $\rightarrow$ `validate_document` $\rightarrow$ `score_confidence`.
  - Idempotency guarantees preventing duplicate simultaneous workflow runs.
